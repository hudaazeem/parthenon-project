x# Pigeon Chase
This is a small browser-based puzzle game made for Parthenon
. 
## Game overview
In this game, the protagonist, a depressed orphan, lost her only photo of her family to a pigeon. She chases the pigeon to get the photo back, and learns a valuable lesson. 

In order to reach the pigeon, she has to go though 3 rooms, and complete minigames to get her picture back.

## Tech used
We used HTML, CSS, Vanilla JS, Google Fonts, and VS Code and Live Server to make our project.
